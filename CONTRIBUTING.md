# Contributing to bashautom

Thanks for considering a contribution!

## Setup

```bash
git clone https://github.com/huskago/bashautom.git
cd bashautom
pip install -e .
pip install pytest
```

## Running tests

```bash
pytest tests/
```

## Making a change

1. Fork the repo and create a branch (`git checkout -b fix/my-fix`)
2. Make your change with a test covering it
3. Run the test suite locally
4. Open a pull request describing what and why

## Reporting bugs

Open an issue with: your OS, Python version, a minimal reproduction, and the actual vs expected behavior.
